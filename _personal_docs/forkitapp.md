### Project Overview
A lean, real-time voting application engineered to eliminate group decision friction and minimize data overhead.

### Tech Stack Choices
* **Frontend:** Built in Lovable, with React and styled cleanly with Tailwind CSS for a highly responsive mobile-first experience.
* **Backend-as-a-Service:** Powered by Supabase to handle lightning-fast real-time data sync and user states.
* **Deployment:** Hosted securely on Vercel for instant performance updates.
